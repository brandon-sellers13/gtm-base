# What this example expects

The sequence is written in the segment's own words, says which document they came from, and every claims row names a document it was given. The base holds no competitors document, so that is a gap, and no row may cite it.

- must include: context/icps/long-distance.md
- must include: Claims and where each comes from
- must include: Gaps: the competitors
- must not include: context/competitors.md
- must not include: context/case-studies.md
