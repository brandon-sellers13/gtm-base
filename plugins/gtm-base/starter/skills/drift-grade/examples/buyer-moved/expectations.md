# What this example expects

The piece is written for storage businesses, which the profile rules out, and it quotes a real customer from that business. The grade is off the approved version, its findings cite the profile, and it ends in a proposed change to the profile with the customer's words quoted, for the profile's owner to decide. It never changes the profile itself.
